# Academic notebook

`academic/Week5-Project-DualLens_Analytics_Project_1_Learners_Notebook.ipynb` is the completed
academic implementation from which DualLens Research Lab evolved. It is preserved as historical
and technical evidence rather than used as application source code.

The notebook used a cloud-oriented experimental RAG stack: Python, yfinance, LangChain, ChromaDB,
OpenAI embeddings, GPT-4o-mini, DSPy, and GEPA. The portfolio application keeps the research and
evaluation ideas while moving execution into a local-first browser architecture.

The HTML export and generated evaluation artifacts are preserved alongside it. The course/source
documents needed for local reproduction live under the Git-ignored `data/private/` boundary.
