# Data boundaries

- `demo/` is reserved for redistributable, precomputed Phase 2 demo data. It is intentionally empty
  in Phase 1.
- `private/` contains local course/source documents and is ignored by Git.

The original PDFs, gold CSV, and course ZIP have not been copied into public demo data because
redistribution rights are not established. They existed in the repository's initial commit; review
and, if necessary, clean Git history before making this repository public. This phase does not
rewrite history.
