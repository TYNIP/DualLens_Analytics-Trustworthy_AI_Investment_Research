# Changelog

All notable portfolio-facing changes are documented here.

## [1.0.0] - 2026-08-23

### Added

- Fourteen-route React/TypeScript research application with deterministic academic Demo Mode
- Browser-native Local AI workflow for PDF extraction, embeddings, scoped vector retrieval,
  grounded WebLLM answers, diagnostics, persistence, and workspace portability
- Accessible responsive navigation, chart alternatives, capability states, progress/cancellation,
  error boundaries, and not-found recovery
- Portfolio case-study and architecture routes
- CI and a gated GitHub Pages workflow for a future sanitized repository
- Public release, deployment, security, attribution, and decision documentation

### Changed

- Promoted the package to portfolio release version `1.0.0`
- Reframed the README as a technical case study with exact academic metrics and limitations
- Reduced release metadata ambiguity with an owned favicon and honest no-live-URL state

### Security

- Audited the working tree and Git history for secrets, restricted material, personal paths,
  ignored local configuration, and accidental artifacts
- Marked the existing Git history unsafe for publication and documented the required clean-repo
  release path without rewriting history
